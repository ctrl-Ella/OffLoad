## Criterios de aceptación

Cómo sabremos que está hecho. Cada línea tiene que poder comprobarla otra persona.

- [ ] Dos personas en navegadores distintos entran a la misma sala y se ven
- [ ] Si se deniega el permiso de cámara, aparece un mensaje que explica qué hacer
- [ ] Se puede entrar y salir usando solo el teclado, con el foco siempre visible
- [ ] El vídeo aparece en menos de 3 segundos desde que se pulsa Entrar
